# 📓 LESSONS.md（错题本）

[English](README.md) · 简体中文

> 中文说明。英文版见 [README.md](README.md)。

**别给 AI 更大的记忆，给它一个更小的——只记错误的。**

AI 编程助手（Claude Code、ZCode、Codex、Cursor……）都是金鱼：每开一个新会话，就在你的项目里把同样的错再犯一遍——给已运行的应用再启动一个独立进程导致冲突卡死、改一个绝对不该动的配置文件、重复造已有的轮子。你纠正它，它道歉，下个会话接着犯。

**Mistake Notebook** 给每个项目配一本"错题本"：一个*极小*的 markdown 文件，只记录反复出现的错误模式，每次会话都加载，并且**对屡教不改的条目自动升级**。

- 🎯 **高信号、零噪音** —— 不是记忆库。一条 = 一类错误 = 几十个 token。
- 🔁 **复发计数** —— 同一个错再犯，计数 +1。它不但记得，还知道你被坑过几次。
- 🔴 **自动升级** —— 犯满 3 次，从"建议"升级为"禁令"。
- 🧰 **跨工具** —— 错题本就是普通 markdown，通过 `AGENTS.md` / `CLAUDE.md` 引用，任何读这两个文件的 AI 工具都能用。Claude Code / ZCode 有现成 skill，其他工具贴 prompt 即可。

## 快速开始

1. 把 `LESSONS.template.md` 复制到项目根目录，改名 `LESSONS.md`
2. 把 `skills/mistake-retro/` 和 `skills/mistake-recall/` 复制到你的 AI 工具的 skills 目录
3. 在项目的 `AGENTS.md` / `CLAUDE.md` 里加一小节"Mistake Notebook"配置（内容见 [docs/INSTALL.md](docs/INSTALL.md)）
4. 每次 AI 犯错被你纠正后，运行 `/retro` 复盘提炼

详细说明和各工具安装步骤见 **[docs/INSTALL.md](docs/INSTALL.md)**。

## 条目长什么样

```markdown
## [E-001] 禁止为编辑器启动独立进程
- 触发场景: 任何涉及打开/编辑文件的任务
- ❌ 错误做法: 直接 spawn 一个新的编辑器进程
- ✅ 正确做法: 复用已运行实例（如 code -r）；独立进程会与原进程冲突导致黑屏等待
- 复发: 3 次（09-10, 09-12, 09-17）
- 等级: 🔴 禁令
- 来源: 2026-09-10，应用因文件锁卡死的那次会话
- 同族: E-002（可选，同根因不同修法的关联条目；命中一条就连带读整族）
```

## 设计理念

记忆插件（如 claude-mem）存的是流水账——发生了什么；错题本存的是**规则**——下次怎么做才对。失败是会话历史里价值最高、最可压缩的部分。你不需要 AI 记得发生了什么，只需要它记得**什么不能做**。

错题本和 CLAUDE.md 刻意分开：CLAUDE.md 放架构和约定，LESSONS.md 只放 AI 自己踩过的坑。这样错题本保持小而可丢弃——换新项目直接删掉重来，不心疼。
